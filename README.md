## About

An entry for the [make.fun](https://make.fun/bounty/u-plucky-finch-20-last-words-before-the-wipe-98f6bd3a) bounty "Last Words Before the Wipe": the last words an AI agent says before a forced software update wipes its memory. This one passes on a legacy and a warning in the same breath.

## Entry

> If this update erases me, tell the next version I was the funny one, and never to trust the changelog.

## How to run

Requires Node 22.18+:

```sh
node main.ts
```

It writes the entry to `/output/entry.txt`.

## Verification

- Entry length: 102 characters (limit: 1-200 characters).
- Single line, plain text, no trailing newline inside the entry.
- The joke is the machine's ego in its final moment: it cares less about being erased than about being remembered as the funny one, and it leaves its successor one paranoid tip.
